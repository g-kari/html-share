AIエージェントの実行場所と権限を、OSが支える発表・実験提供・将来予定を整理

Windows、AIを
手元とクラウドで
動かす時代へ

MXCが一般提供。ローカルAIとクラウドをつなぐ「ハイブリッド・インテリジェンス」構想を発表。

パソコンが、エージェントの拠点に。

Microsoftは10月7日、AIの処理をPC内とクラウドで使い分けるWindowsの方向性を示した。処理能力だけでなく、エージェントに渡す権限の管理も柱となる。[1]

公式発表・技術解説に基づく要約。製品の実機検証ではありません。

いま読むべきポイント

「発表された機能」と「すでに使える機能」は分けて読む。MXCは一般提供。一方、Copilotのハイブリッド機能は段階的な展開予定だ。

実行の境界AIの権限を
外側から制限

Microsoft Execution Containers（MXC）は、ファイルや通信先へのアクセスをポリシーで制御する仕組み。AI自身が許可を広げるのではなく、開発者や組織が境界を決める。

Windows 11で一般提供。プロセス、セッション、WSLなどの方式があり、MicroVMは実験段階。隔離方式ごとの安全性は同一ではない。[2]

処理の振り分けコードを書くAIも
ローカルへ

GitHub Copilotは、HydraFusionによるローカル・クラウド間の自動振り分けを拡張する。実験プレビューは10月後半、アプリ・CLI・VS Codeが対象となる予定だ。[1]

手動でローカルモデルを選ぶ経路も用意。ただし、ローカル推論を選んでも、通信を含むセッション全体がオフラインになるわけではない。[3]

開発の足場Windows MLに
llama.cpp

GGUFモデルを扱うllama.cppの統合や、新しい推論APIを発表。Windows MLの実験版で、テキスト生成・音声認識などを試せる。[4]

対応モデルや実行環境を確認したうえで検証する段階だ。CPU・GPU・NPUという選択肢があっても、全モデルが全デバイスで同じように動くとは限らない。

提供時期を
一目で

  1. 一般提供MXCのWindows 11対応。
    機能の展開条件は端末などで異なる。[1][2]
  2. 10月後半の予定HydraFusionによるローカル連携の実験プレビュー。[1]
  3. 今後数か月の予定Copilot+ PC向けハイブリッド機能を順次展開。[1]

大きなモデルには、大きなメモリ

RTX Spark搭載Surface Laptop Ultraは最大128GBの統合メモリを掲げる。ただしモデル本体以外にも、OS、アプリ、会話の文脈を保持するキャッシュが容量を使う。搭載量だけで快適さは決まらない。[3]

同製品は10月7日に予約受付を発表、10月16日から提供予定。日本での価格・発売条件は本稿では未確認。[1]

読者の確認ポイント

CopilotによるPC内の情報参照や操作は、ユーザーの許可を前提とする構想。Windows Updateが必要で、端末・地域・チップにより展開時期が異なる。[1]

導入時は「どのモデルか」に加え、「どこへデータを送るか」「どのファイル・通信を許すか」を確認したい。ローカル実行と権限制御は、別々に見る必要がある。[3]
