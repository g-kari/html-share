用語集

このサイトの記事に出てくる専門用語の短い説明です。記事本文では、辞書に登録された用語が最初に出てくる場所に、この用語集へのリンクが自動で付きます（1記事につき同じ用語は1回まで）。

説明は一般的な意味を優先し、特定の製品や記事での使われ方が一般と違う用語は、その使われ方も併せて書いています。用語の正本はリポジトリの辞書ファイルで、このページの一覧は生成時に辞書から作られます。

土台の技術

ランタイム
プログラムを実行する土台となるソフトウェアや実行環境のこと。
eBPF
Linuxカーネル（OSの中核部分）の中で、小さなプログラムを決められた地点で動かす仕組み。処理や通信を観察したり、条件に合う動きを差し止めたりするために使われます。
Tetragon
Isovalentが公開した、eBPFベースの監視と実行制御の基盤。プロセスや通信の動きを観察し、決めたルールに合わない動きを止めます。
コードパス
プログラムが処理を進めるときに通る命令の道筋のこと。「脆弱なコードパス」は、攻撃に使われる入力が通る特定の道筋を指します。
eBPF verifier
eBPFプログラムをカーネルへ読み込む前に検査するLinuxの仕組み。終わらない処理や範囲外のメモリアクセスなど、安全でないプログラムを読み込み前に弾きます。
同期エンジン
複数の端末や画面の間で、データの状態をそろえ続けるための仕組み。表示を手元で先に反映し、裏側でサーバと同期する形がよく使われます。
バックポート
新しい版に入った修正を、古い版のソフトウェアに取り込んで直すこと。版番号は変わらないまま、特定の不具合や脆弱性への修正だけが反映されます。
部分関数適用
関数の引数の一部を先に固定し、残りの引数を受け取る新しい関数（クロージャ）を作る書き方。PHP 8.6ではプレースホルダ ? と ... で書ける。
ポーリング
複数の入出力先をまとめて監視し、読み書きできるようになったものを通知する仕組み。OSの epoll や kqueue を使うと、多数の接続を効率よく扱える。
Code Mode
AIエージェントにツールを1つずつ呼ばせず、ツールを呼ぶコードを書かせてサンドボックスで実行する方式。ツール定義をモデルの文脈に常駐させる量を減らし、複数呼び出しの連鎖をコードの中で済ませる。
ファイルストレージ
サービス内にファイルを保存できる容量の枠のこと。ワークスペースやアカウント単位で上限が決まる場合、アップロードしたファイルの合計サイズがその枠を消費する。

保護の仕組み

shield
恒久パッチが届くまでの間だけ使う、小さな緩和策。Shirudoの発表ではshield、本体リポジトリではupatch（マイクロパッチ）と呼びます。脆弱な経路を塞ぐ、脆弱なコードを修正済みのコードへ置き換える、といった働きをします。
監視モード
実際には止めずに「止めるはずだった動き」を記録だけする状態。影響を確認したあと、実際に止める状態へ切り替えることが適用（Enforce）です。
TPM
コンピュータに載るセキュリティ用のチップ。鍵の保管や、読み込まれたソフトウェアの記録を行い、あとから記録が改ざんされていないか確かめるために使います。
attest
「このマシンには、このソフトウェアや保護が読み込まれている」という証跡を提示すること。受け取った側は証跡を検証して、記録が改ざんされていないか確認できます。
OCIレジストリ
OCIはコンテナイメージなどの配布形式を定めた標準で、レジストリはその配布物を置くサーバです。プル型配布は、配る側が対象へ送り込むのではなく、対象側が取りに行き、署名を確かめてから使う方式を指します。
常駐デーモン
デーモンは裏で動き続ける常駐プログラム、CLIはコマンドを打って操作する道具です。ワンショットCLIは、コマンドを1回実行して終わる形の操作を指します。
制御プレーン
実際に処理を行う部分に対して、何をどう動かすかを決める部分のこと。

実証と導入条件に出てくる用語

Java4Shell
OpenJDKにある脆弱性の通称。細工した入力によって、本来できない上書きなどを引き起こす問題です。影響条件は当サイトのJava4Shell解説で扱っています。
OpenJDK
Javaの実行環境のオープンソース実装。Javaプログラムはこの上で動きます。
Javaバイトコード
Javaのソースコードを変換した中間形式のコード。実行環境がこれを読み込んで動かします。
Base64
バイナリデータを英数字などの文字列で表す変換方式。
Elasticsearch
検索エンジンのソフトウェア。ログや文書の検索・集計に広く使われます。
ABI
プログラム同士、またはカーネルとプログラムの間で、データの渡し方や呼び出し方を定めた約束事。約束が合わないと正しく連携できません。
署名付きローダー
ローダーはプログラムや保護を読み込む仕組みです。署名付きローダーは、そのローダー自体が信頼できる署名を持つものに限られる仕組みを指します。
カーネルパッチ
Linuxカーネル（OSの中核部分）自体への修正のこと。
プレリリース
正式版より前の公開段階。仕様や要件が変わる前提で、評価や検証のために出す状態を指します。
デュアルライセンス
一つの成果物に複数のライセンスを併記し、利用する側が条件を選べる形。

セキュリティ一般

フィッシング
本物そっくりのメールやサイトで、パスワードやカード情報などを入力させる手口。
マルウェア
利用者の意図に反する動作をする悪意のあるソフトウェアの総称。ウイルスやランサムウェアを含みます。
ランサムウェア
感染した機器のデータを暗号化するなどして使えなくし、復旧と引き換えに金銭を要求するマルウェア。
ゼロデイ
修正パッチがまだ提供されていない脆弱性や、その脆弱性を突く攻撃のこと。
SBOM
ソフトウェアを構成する部品（ライブラリ等）の一覧表。脆弱性の影響範囲を調べるために使います。
サプライチェーン
ソフトウェアや製品が作られ、届けられるまでの供給の連なり。その途中の部品や配布経路が狙われる攻撃をサプライチェーン攻撃と呼びます。

サービスと料金

ChatGPT Sites
ChatGPTとの対話でウェブサイトや軽量なアプリを作り、そのまま公開・共有できるOpenAIの機能。Plus、Pro、Business、Enterpriseで利用できます。
ホスティング
作ったウェブサイトやアプリをサーバ上で公開し、アクセスできる状態に保つこと。トラフィックや保存量に応じて料金がかかる場合があります。
カスタムドメイン
自分で所有するドメイン名を、サービスの既定のアドレスの代わりにサイトの公開先として使うこと。ドメインの登録費用は別にかかります。
T3 Chat
OpenAIやAnthropic、Googleなど複数社のAIモデルを、1つの画面で切り替えて使えるチャットサービス。運営は米国のT3 Tools。
BYOK
サービス側の利用枠ではなく、利用者自身のAPIキーを持ち込んで使う方式。料金はキーの発行元へ直接支払います。

開発ツール

T3 Code
Claude CodeやCodexなどのコーディングエージェントを、自分のマシンで動かしたまま、デスクトップ・Web・スマホの1つの画面から操作する無料のオープンソースアプリ。運営は米国のT3 Tools。
ハーネス
LLMに道具の呼び出しや結果の受け渡しを担わせ、エージェントとして動かすための実行基盤。Claude CodeやCodexの中核部分を指します。
Gitワークツリー
1つのGitリポジトリから複数の作業フォルダを切り出す仕組み。フォルダごとに別のブランチを開けるため、複数の作業を並行して進められます。
T3 Connect
T3 Codeのリモート接続の仕組み。自分のマシンで動くエージェントへ、スマホやブラウザから接続するために使います。
ACP
エージェントと、それを操作するクライアントの間の通信手順を定めたプロトコル。対応するエージェントは共通の方法で別の画面から操作できます。
Orca
複数のコーディングエージェントを、タスクごとのGitワークツリーで並行実行するための無料のオープンソースのデスクトップアプリ。エージェント開発環境（ADE）を名乗ります。運営はStably。
ADE
AIエージェントと一緒に開発するための環境。人間がコードを書くためのIDEに対し、エージェントの並行実行や作業場所の管理まで含めて設計されたものを指します。
Orca Bots
Orcaの中で動くボット。SlackやLinearなどから仕事を受け、利用者自身のマシンと契約でエージェントを動かし、プルリクエストを返します。
コーディングエージェント
コードの読み書きやコマンド実行を自律的に進めるAIツール。Claude CodeやCodexなどが該当し、利用はモデルの提供元の契約に基づきます。
AWS Emulator
AWSのサービスを自分のコンピュータやCI環境で再現するローカルエミュレータ。SDKやCLIの呼び出し先を変えるだけで、デプロイなしにテストできます。
AG-UI
エージェントと利用者向け画面をつなぐためのオープンなプロトコル。エージェントの状態やツールの実行、人の承認などを双方向にやり取りする形式を定めます。

AI基盤

Amazon Bedrock AgentCore
AIエージェントの実行環境、メモリ、ID、ツールをまとめたAWSのマネージド基盤。エージェントを本番で動かすための土台を提供します。
Strands Decider
テキストを生成せず、選択肢ごとの確率を返す判断専用のオープンモデル。ルーティング、ツール選択、ガードレールのような細かい判断に使います。
AIコワーカー
人の同僚のように常駐し、チャットやメールで受けた仕事を自律的に進めるAIエージェントの呼び方。承認が要る場面だけ人に確認に戻る形が一般的です。
Grok Bot
xAIが2026年8月にベータ公開したAIコワーカー。各Botがクラウド上の専用コンピュータを持ち、既存ツールにサインインして働きます。このジャンルの起点とされる製品です。
Skills over MCP
MCPサーバーが、ツールと一緒にAgent Skills（仕事の手順書）を公開できるようにするMCPの拡張。クライアントはスキルを必要な時だけ読み込み、内容はサーバーの更新に追従する。
Agent Skills
エージェントに特定の仕事の手順や知識を与えるための公開標準。SKILL.mdを中心に、指示・スクリプト・参考資料を1つのフォルダ（スキル）にまとめる。
MCP Tasks
MCPのツール呼び出しを非同期化する拡張。サーバーは最終結果の代わりにタスクIDと状態を返し、クライアントは状態を確認しながら結果を後から受け取る。
Elicitation
MCPサーバーが処理の途中で利用者へ入力や承認を求める仕組み。課金や削除のような確認が要る操作の前に、フォームやリンクで問い合わせてから処理を続ける。
Daybreak Defense Factory
OpenAIのDaybreakにおける防御側の仕組み。エージェントが脆弱性を調査して修正案（パッチ）を用意し、開発者のレビューとテストを経て取り込む流れを担う。
エージェント型修復
AIエージェントが検出結果の調査から修正案の作成までを担う修復の進め方。最終的な判断とマージは人が担う前提で語られることが多い。

セキュリティ

Nitro Sandboxes
EKSのPodやECSタスクなどを、それぞれ専用の軽量仮想マシンでハードウェア分離して動かすAWSの仕組み。1台のインスタンスを共有しながら分離境界を保ちます。
Strands Box
コーディングエージェントをOSレベルのサンドボックスで動かすオープンソース。ファイル、コマンド、ネットワーク、MCPの呼び出しをポリシーで検査します。
Amazon Inspector
AWSの脆弱性管理サービス。EC2インスタンス、ECRのコンテナイメージ、Lambda関数、AMI、コードリポジトリを継続的にスキャンし、ソフトウェアの脆弱性と意図しないネットワーク露出を検出結果として報告します。
ランタイム到達性分析
脆弱なパッケージが実行時に実際に使われる場所にあるか、動いているかを判定し、検出結果の優先付けに使う分析。Amazon InspectorではECRのコンテナイメージとEC2インスタンスの検出結果に付きます。
JWTオーソライザー
Amazon API GatewayがJSON Web Token（JWT）をゲートウェイ自体で検証するオーソライザー。信頼する発行者、audience、署名アルゴリズム、追加クレームを設定で宣言し、Lambda関数なしでOIDC／OAuth 2.0のトークンを検証します。
API Portal
Amazon API Gatewayの機能。API Gateway、Application Load Balancer、CloudFrontの背後にあるAPIを、トラフィックログとサービス設定レコードから自動発見して台帳化し、セキュリティ態勢を評価します。発見したAPIのドキュメントポータルも作れます。
シャドウAPI
組織内に実在して到達できるのに、管理下に置かれていないAPI。API Portalでは発見されたAPIはすべてシャドウAPIとして台帳に現れ、昇格させることで管理対象になります。
ゾンビAPI
管理対象のAPIのうち、長期間トラフィックがなく設定変更もないもの。API Portalでは、30日間トラフィックがなく、かつ裏付けリソースの設定変更が90日間ない管理対象APIを指します。
SameSite
Cookieに付ける属性で、別のサイトからのリクエストにそのCookieを送る範囲を決める。Laxでは通常のクロスサイトPOSTにCookieが付かず、Strictでは別サイトからの遷移でも送られない。
セッションフィクセーション
攻撃者が用意したセッションIDを被害者に使わせ、そのIDのままログインさせることでセッションを乗っ取る攻撃。サーバーが発行していないIDを拒否する strict mode が対策になる。
バックドア
攻撃者がシステムへ繰り返し侵入するために仕掛ける、通常の認証を通らない裏口のこと。見つけた場合は除去と侵入経路の修正が再開の前提になる。
Wiz Security Graph
Wizがクラウド環境の資産、公開状態、IDと権限、機密データを相互の関係として表したグラフ。検出結果を攻撃経路や到達可能性と結び付けて評価するために使う。
実効権限
ポリシーや継承をすべて適用した結果として、実際に効いている権限のこと。設定上の許可の見た目と、実際に到達できる範囲がずれる場合の評価に使う。

コンピュート

durable functions
AWS Lambdaで、チェックポイントと自動リトライを持ち、最長1年動ける多段処理を書くための仕組み。途中で待機しても計算料金はかかりません。
マシンイメージ
EC2インスタンスを起動するためのテンプレート。OSやソフトウェア一式を含みます。代表例がAmazon Machine Image（AMI）です。

運用・障害対応

緊急メンテナンス
障害やセキュリティ上の問題に対応するため、予定外にサービスを止めて行う保守作業のこと。原因の調査、修正の適用、安全性の確認が終わるまで再開しないことが多い。
