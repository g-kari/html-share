AI開発ツール解説 · Orca

Orcaとは：Claude CodeやCodexをワークツリーごとに並行実行する無料のエージェント開発環境（ADE）

確認日：2026年11月24日
一次資料：Orca公式サイト／GitHubリポジトリ（README）。公式で確認できない箇所は、本文と出典に明記します。同名の別製品（音声合成ソフトや分散型取引所のOrcaなど）とは無関係です。

要点
  1. Orcaは、複数のコーディングエージェントを並行して動かすためのデスクトップアプリです。公式は「ADE（エージェント開発環境）」と呼び、人間がコードを書くためのIDEではなく、エージェントと一緒に開発するための環境だと位置づけています。運営はStably（GitHub組織は stablyai）で、公式サイトにはY Combinatorの支援が表示されています。
  2. 中心の仕組みはGitワークツリーです。タスクごとに本物の git worktree を切り出し、エージェントごとに作業フォルダを分けるため、複数のエージェントが同じリポジトリで同時に働いても衝突しません。ターミナル、diffレビュー、ブラウザ、GitHub／Linear連携が1つの画面に入っています。
  3. Orca自身はAIモデルを持ちません。動かすのは利用者がすでに契約している各エージェントのCLIで、課金は各提供元の契約のままです。アプリ本体は無料で、ソースコードはMITライセンスで公開されています。
  4. 「Orca Bots」という機能では、SlackやLinear、GitHubなどから仕事を頼むと、ボットが自分のマシンで自分のClaude CodeやCodexを使い、テスト済みのプルリクエストを返します。判断が要る場面では「Needs you」として止まり、デスクトップやスマホから答えると再開します。
  5. GitHubリポジトリの公開は2026年3月です。スターは2026年11月24日時点で13万5千を超え、最新版はv1.4.272（2026年11月23日）で、公式が「毎日出す」と言うとおり更新が非常に速いプロジェクトです。
  6. 同じく複数エージェントを扱うT3 Codeとは、管理の単位が違います。T3 Codeが「スレッド」中心の操作画面なのに対し、Orcaは「ワークスペース＝ワークツリー」中心の開発環境です。違いは本文で比べます。

Orcaとは

Orcaは、Claude CodeやCodexなどのコーディングエージェントを複数、同時に走らせるためのデスクトップアプリです。公式サイトの見出しは「The agent development environment」で、FAQでは「無料でオープンソースのデスクトップアプリ」と説明されています。エディタの代わりにエージェントを置くのではなく、ワークツリー、ターミナル、diffレビュー、ブラウザをまとめた「エージェントのための開発環境（ADE）」という言い方をしています。

想定する使い方は、タスクごとに作業場所を分けてエージェントを並行させることです。たとえば認証まわりをClaude Code、APIをCodex、フロント画面をOpenCodeに任せ、出来上がったdiffを並べて確認し、よいものを採用します。同じエージェントを複数起動して同じタスクを競わせる使い方も公式FAQが挙げています。

運営はStablyです。GitHubの組織は stablyai、リポジトリ（stablyai/orca）の作成は2026年3月17日、主な実装言語はTypeScriptです。公式サイトにはY Combinatorのロゴと「Backed by Y Combinator」の表示があります。

仕組み：ワークツリーで作業場所を分ける

Orcaは「ワークツリー・ファースト」を掲げています。各エージェントは専用の隔離されたGitワークツリーの中で動きます。ワークツリーはGit標準の仕組みで、1つのリポジトリから複数の作業フォルダを切り出し、フォルダごとに別のブランチを開けます。Orcaが作るのは本物の git worktree なので、通常のgit操作もそのまま使えます（公式FAQ）。

作業の流れは、リポジトリの既定ブランチからワークツリーを切り出し、エージェントを割り当て、並行して進め、diffを比べて採用する、という形です。同じファイルを複数のエージェントが同時に触らないため、並行作業同士が衝突しません。

エージェントとの対話は、チャットUIでも生のターミナル（CLIそのまま）でも行え、文脈を失わずに両方を行き来できます。ターミナルはGhostty系の分割機能を持つものが内蔵されています（公式FAQ）。

実行場所は自分のマシンが基本ですが、Remote Orca Serverとのペアリング、SSHホスト上での実行、ワークツリー専用のクラウドVMも選べます。リモートで動かせば、ノートPCがスリープしてもエージェントは動き続けます（README）。

Orca Bots：チャットから頼めるボット

Orca Botsは、Orcaの中に住むボットです。公式FAQによると、各ボットは利用者自身のClaude CodeやCodexを、利用者自身のマシンで動かし、Slack、Linear、GitHub、Gmail、スケジュール、Webhookから仕事を受けます。ボットはGitワークツリーの中で作業し、必要に応じて並行ワーカーを起動します。

公式サイトの説明では、SlackやLinear、GitHubでボットに「このバグを直して」と頼むと、戻ってきたときにはテスト済みのプルリクエストができている、という流れです。途中で判断が要る場面になると「Needs you」に挙がり、デスクトップでもスマホでも、質問に答えれば作業が再開します。手を入れたくなったら、そのスレッドをOrcaで開けばエディタ、ターミナル、ブラウザがそろっています。

ボットのスケジュールとトリガー（平日9時に実行、PRが開いたら実行、チェックが失敗したら実行、Webhookで実行）も用意されています。ボットの人格と記憶は SOUL.md と MEMORY.md というプレーンなMarkdownファイルに置かれ、読んだり編集したりできます（README）。

対応するコーディングエージェント

公式の言い方は「ターミナルで動くCLIエージェントなら何でも」です。READMEには名前つきで多数が挙がっています。代表例はClaude Code、Codex、Grok、Cursor、GitHub Copilot、Muse、OpenCode、Amp、Antigravity、Pi、Hermes Agent、Devin、Goose、Cline、Continue、Kiro、Qwen Codeなどで、このほかにも多くの名前が並びます。前提は、各エージェントのCLIがそのマシンに入っていて、利用者自身の契約でログインが済んでいることです。

エージェントの利用量とリセット時期をOrcaの中で確認したり、ログアウトせずにアカウントを切り替えたりする機能もあります（公式サイトのUsage & Accounts）。

主な機能

  • diffレビュー：変更行そのものにメモを書き、その注記をエージェントへ返して直させることができます。
  • Git連携：diffからコミットメッセージとプルリクエストを下書きし、失敗したチェックやPRのレビューコメントをエージェントへ送って直させることができます。
  • GitHub／Linear連携：課題をアプリの中で見て、課題ごとにワークスペースを開始できます。
  • エージェントの分担（Orchestrate Agents）：大きなタスクを1つのエージェントに渡すと、仕事を分割してワーカーエージェントを各自のワークスペースで起動し、結果を持ち帰ります。
  • Orca CLI：アプリでできることはコマンドラインからもでき、エージェント自身がワークツリーの作成、ワーカーの起動、ブラウザやデスクトップアプリの操作、自動化のスケジュールを行えます。
  • Automations：リポジトリごとにプロンプトをスケジュール実行できます。例として夜間の依存関係更新、週次のトリアージ、不安定なテストの洗い出しが挙げられています。
  • Design Mode：内蔵ブラウザで要素をクリックすると、そのHTML、スタイル、セレクタをコピーしてエージェントのチャットへ貼れます。
  • そのほか：画面分割（Split Anything）、モバイルエミュレータ、音声入力（Dictation）、Computer Use（CLIやAPIがない場面でデスクトップアプリを操作）、プラグインなど。

T3 Codeとの違い

どちらも「複数のコーディングエージェントを、自分の契約のまま、自分のマシンで動かす」ための無料のオープンソースです。違いは管理の単位と画面の作りです。

項目T3 CodeOrca
管理の単位スレッド（作業の会話）ワークスペース＝Gitワークツリー
軸になる使い方途中でのモデル／エージェント切替と引き継ぎ複数エージェントの並行実行とdiffの比較・採用
形態自分のマシンで動く小さなサーバ＋デスクトップ／Web／スマホのクライアントIDE型のデスクトップアプリ＋モバイルコンパニオン
ワークツリースレッドごとに分けることができるワークツリー・ファーストで、作成が作業の起点
仕事の受け方画面から指示するのが中心画面に加え、Bots（Slack等）とAutomationsで受ける
運営T3 Tools, Inc.Stably
料金無料（MIT）。接点としてT3 Connectの上限がT3 Chatプランと連動無料（MIT）。有料プランは公式に用意されていない

ざっくり言えば、1つの作業を進めながら相棒を切り替えるならT3 Code、複数の作業を同時に走らせて結果を比べるならOrca、という向きの違いです。T3 Code側の詳しい内容はT3 Codeの記事にまとめています。

料金

Orca本体は無料です。公式FAQの「Is Orca free?」への答えは「完全に無料で、MITライセンスのオープンソース」で、公式サイトにも価格は0ドルと表示されています。有料プランは、確認した公式資料の範囲では用意されていません。

払う必要があるのは、Claude CodeやCodexなど、自分が使うエージェントの契約料だけで、それはOrcaを使う前と同じです。Orca側がトークンを再販したり、利用量メーターで課金したりすることはありません。リモート実行でSSHホストやクラウドVMを使う場合は、その環境自体は自分の用意したものを使います。

データの扱い

実行は自分のマシンが基本で、エージェントは利用者自身の契約とログインで動きます。ボットについても公式FAQは「自分のマシンで、自分のClaude CodeやCodexを使う」と明記しています。リモート実行を選んだ場合も、接続先は自分のSSHホストや自分のクラウドVMです。

利用状況データについては、READMEが公式のプライバシー／テレメトリ文書へ案内しています。そこでは、Orcaが収集する匿名の利用状況データの内容と、オプトアウトの方法が説明されています。導入時に気になる場合は、その文書を確認してください。

導入の流れ

デスクトップ版はmacOS、Windows、Linuxに対応し、公式サイト（orca.dev）からダウンロードできます。macOSはHomebrewでも入れられますが、その際は brew install --cask stablyai/orca/orca とフルネームで指定します。素の orca は無関係のPlotlyのcaskだとREADMEが注意しています。LinuxはAppImageのほか、Arch Linux向けのAURパッケージ（stably-orca-bin）もあります。

前提は、少なくとも1つのエージェントのCLIが入り、ログインが済んでいることです。アプリにリポジトリを追加すると、既定ブランチからワークツリーを切り出して作業を始められます。モバイルアプリ（iOS／Android）はデスクトップとペアリングして使うコンパニオンで、エージェントが入力を待っているときの通知、チャットでの返信、外出先からの進行確認に使います。
