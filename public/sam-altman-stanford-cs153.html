要点

スタンフォードへの帰還0:09

この授業は、Altman が2014年に教えた CS183「How to Start a Startup」に着想を得て設計された。Altman は、スタートアップの作法は当時から根本的に変わっており、誰かがアップデート版を教えるべきだが、自分はたぶんやらないと述べた。OpenAI の創業は2016年で、CS183 で理論を組み立ててから実行に移したように見えるが、実際はそう単純ではなかったという。

OpenAIは「逆さまのスタートアップ」1:29

通常のスタートアップは製品会社として始まり、成長が鈍ってから研究所を後付けする。OpenAI は逆で、研究所が先にあり、会社を後付けした。Altman はこの順序を勧めはしないとしつつ、AI がまだ存在しなかった時代には AI 以前の作法で進めるしかなかったと説明した。いまの優れたスタートアップの動き方は数年前とも大きく違う、というのが全体の前提になっている。

最大の変化はトークン支出2:25

CS183 を更新する場合の最大の変更点として挙げたのがこれである。手頃な金額のトークン支出で、100人規模の優秀な開発チームが行う仕事ができるようになった。これは以前はスタートアップの選択肢に存在しなかった。結果として、狙える野心の大きさ、動く速度、同時に進められる仕事の量が変わったと述べた。

良い課題は出題できない3:11

授業の課題として「取り組むべき問題」を出題する方式は機能しない、という話。自分が思いつける良いアイデアは、大抵ほかの大勢も思いつく。狙うべきは、自動コーディングの時代になって初めて可能になった、非自明で巨大な市場である。OpenAI 創業の時点では、AGI に取り組む組織は世界で4つほどしかなかった、という例を引いた。課題として割り当てられる種類のアイデアは、たいてい本命ではないという。

スケールが生む創発性4:59

理論的な説明はできないと断ったうえで、経験則として、面白い成果はスケールを押し上げた先に出ることが多いと述べた。モデルのスケーリング則だけでなく、Y Combinator のバッチ内ネットワーク効果のように、10分の1や100分の1の規模では存在しなかった性質が現れる。小さい規模で面白く動いているものを、誰も試していない規模まで押し上げる試みは、多くの人が十分にやっていないという。

スケールで壊れるものを分解する8:00

スケールすると、ものは加速的に、予測できない形で壊れ続ける。AI モデルの大規模化では、1万台・10万台の GPU を使う学習が技術的に可能かという問題、資本をどう集めるかという問題、計算資源を1つのプロジェクトに集中させることへの研究者文化の反発、という3面があった。各面を分けて1つずつ対処することが、システム設計としての要所だという。

人の側をスケールさせる10:27

組織の側では、明確な目標、到達までの計画、途中の意思決定の仕方を共有することが重要だという。「スケーリングに賭ける。外れたら失敗するが、これをやる」と決めて理由と到達後の姿を示すことが力になる。一方で人は指数関数的な伸びを想像するのが苦手で、第一原理から一緒に考える時間が必要になる、とも述べた。

ChatGPTはどう見つかったか12:43

GPT-3 を作ったが製品が思いつけず、収益化のために2020年夏に API として公開した。しばらく反応はなく、約1か月後に Twitter で広がった。事業として成立したのはコピーライティングだけだったが、開発者が API キーを使ってチャットをしていることが分かり、チャットボットを作ることにした。研究デモのつもりで出した ChatGPT は公開直後から伸び続け、5日目には「当たる」と確信したという。そこから会社と製品を同時に作る緊急事態になり、2か月の大規模な拡張が続いた、という経緯である。

Codexと「手足」の考え方16:41

ChatGPT 以前の本命はコードだった。モデルにとってコードはコンピュータを操作する手足であり、ロボットは物理世界を操作する手足だ、というのが当時の考え方である。十分に賢いモデルにこの2つの手足を持たせれば、世界の中で実際に仕事をさせられる。Codex は今年の初めに実用域に入り、5.5 で転換点を迎えたと述べた。

学習パイプラインはいずれ書き換わる17:31

事前学習・中間学習・事後学習という現在のパイプラインは現行の形であり、最適解には見えず、いずれ大きく書き換わると予想した。書き換え自体が AI の研究課題になる、という見方も示した。社内目標として、今年9月に50万台の A100 相当 GPU を AI 研究インターンとして使い、2028年3月までに新しいアーキテクチャを自力で考える自律的な研究者を実現することにも触れた。

知能は新しいユーティリティになる19:57

いま起きているのは、新しいユーティリティ（電気、水道、インターネットに続く基盤）の生成だという。電気が広まったとき、電力会社は「電気」そのものではなく「夜の明かり」を売った。知能も同じで、トークンのサブスクリプションをあらゆるものに差して使う世界が来ても、「知能を売っている」という説明では利用者に響かない。ユーティリティになるには、利用者が理解できる形で届ける必要があると述べた。

買うのはコンピュートではなくトークン22:50

利用者はチップの種類や設置場所を意識せず、トークン、あるいはエージェントが常時動き続ける単位で買うようになる、という見方を示した。携帯電話の料金で基地局のハードウェアを考えないのと同じである。授業の最終課題「一人フロンティアラボ」への助言として、自分なら推論の側、つまり知能を安く大量に届ける仕組みに取り組むと述べた。優れたモデルはどのみち出てくるが、安く豊富な知能の供給は投資が不足しており、フロンティアラボは今後、推論の会社になっていくという。

Q&A：LLMは行き止まりか25:53

Yann LeCun らの「LLM は行き止まり」という見方への回答。モデルは人間の能力を一部では大きく超えており、前日にモデルが Erdős の予想を反証した例を引いて、LLM が新しい知識を生めることは示されたと述べた。一方で、長い時間軸と高い判断力が要る仕事はまだ苦手だとも認めた。信念をアイデンティティにしてしまうと、データが出ても真実を見られなくなる、という指摘もした。

Q&A：教育はまだ変わっていない29:03

ChatGPT 公開から3年半が経ったが、教育制度に目立った変化は見られず、これは自分の予測の誤りだったと述べた。前 AGI 時代の教え方と評価を続ければ、考える力は衰える。書くことのように、考える力を鍛えるための科目は、機械のほうが上手でも教える意味がある。ただし教え方と評価の多くは全面的に変えるべきだ、という立場である。スタンフォード時代については、入門セミナーで幅広い分野に浅く触れた経験が、振り返ると大きかったと述べた。

Q&A：今後10年の分岐32:17

最も大きな分岐は、この技術が広く民主化されるか、少数の企業に集中するかだという。集中は不安定で不公平なだけでなく、アラインメントの失敗でもあるとし、民主化の道に進む確率を80%と見積もった。分配の方法については、ベーシックインカムのような現金の定期給付より、市民が資本の一部を持つ仕組み（市民富ファンドのような形）に期待を示した。もう1つの論点は、UBI や富の分配の前に、コンピュートをどう公平に配るかだという。

Q&A：コンピュート不足は続く38:45

巨大なコンピュート不足があることは認めた。需要は価格で決まる面が大きく、電力と同じで価格が10分の1になれば必要な量の見積もりは全く変わる。モデルが賢く安くなるほど使いたい量が増えるため、進歩が続く限り不足は続くかもしれないと述べた。個人エージェントを10個、100個と常時動かす世界では、推論の需要はさらに増える、という見通しである。
