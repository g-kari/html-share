Amazon Bedrock AgentCore 2026年11月の変更：次世代ランタイムが既定に

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. 中心は次世代ランタイムの既定化（11月12日）。起動は最大15倍、セッションは最大8 vCPU／32GB、アイドル時はゼロへ縮小します。
  2. ランタイムインスタンスは特権モード、入れ子仮想化、G7 GPUに対応し、GovCloud（US-West）でも一般提供になりました。
  3. Memoryは短期メモリの保持が最大10年に延び、セッション要約が入りました。IdentityはOAuthディスカバリURLとPrivate CAに対応しました。
  4. Web Search APIとWeb Answerが出て、Web Searchには月5,000クエリの無料枠。Marketplaceではエージェント決済が始まりました。

概要

Amazon Bedrock AgentCoreは、AIエージェントの実行・メモリ・ID・ツールをまとめたマネージド基盤です。2026年11月は関連発表が14件あり、中心は11月12日の「次世代ランタイムが既定化」です。起動の高速化と大きなセッション、アイドル時のコスト削減が打ち出され、周辺ではMemoryの長期保持、Identityの認証まわり、ウェブ検索、エージェント決済がそろって更新されました。

ランタイム：次世代が既定に、インスタンス実行も拡張

次世代ランタイムは、セッション起動が最大15倍、セッション規模は最大8 vCPU／32GB（従来の4倍）で、アイドル中のエージェントはゼロまで縮小し、S3ファイルシステムのマウントにも対応します（いずれもAWSの説明）。各セッションがハードウェア分離された専用microVMで動く点は変わりません。

EC2容量をAgentCoreが管理する「ランタイムインスタンス」も拡張が続きました。特権モード（システムレベルのソフト導入や入れ子コンテナ）、入れ子仮想化（KVMでVMやエミュレータを実行）、G7インスタンス（NVIDIA RTX PRO 4500 Blackwell GPU）の対応が入り、提供リージョンは6リージョン追加とGovCloud（US-West）での一般提供まで広がりました。

MemoryとIdentity

Memoryは、短期メモリの保持期間が最大10年（従来1年）に延び、全セッションの要約を保持する「セッションサマリー」が入りました。IdentityはOAuth 2.0ディスカバリURLとプライベート認証局（Private CA）に対応しました。あわせてセキュリティ側では、STSのGetScopedCredentials（実行時に権限を絞り込むAPI）がセキュリティまとめに入っています。

ツールと決済

ツール面では、自然言語の質問に出典つきで答える「Web Answer」（11月5日）とWeb Search API（11月10日）が出て、Web Searchには月5,000クエリの無料枠が付きました。決済では、AWS MarketplaceがAgentCoreによるエージェント決済に対応し、エージェントがリクエスト単位で支払ってAWSの請求に集約できるようになりました。
