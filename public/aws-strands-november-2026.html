Strands 2026年11月の発表：判断モデルDecider v2とサンドボックスBox

確認日：2026年11月24日
一次資料：Strands公式ブログ（2026年11月23日）。What's Newへの投稿はありません。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. Decider v2は、テキストを生成せず選択肢ごとの確率を返す判断専用モデルです。Gemma 4ベースの5サイズ（E2B〜31B）、Apache-2.0で、ルーティングやツール選択、ガードレールに使います。
  2. Strands BoxのCLIがClaude Code、Codex、Kiro CLIにネイティブ対応しました。box run claude で、自分のマシンのエージェントをOSサンドボックスの中で起動できます。
  3. Boxはファイル・コマンド・ネットワーク・MCPをポリシーで検査し、判定はモデルの外で行います。認証情報は箱の外に置かれ、出口で実キーに差し替わります。

概要

Strands Agentsは、AWSがオープンソースで開発するエージェント向けSDKです。2026年11月23日に、判断専用モデル「Strands Decider v2」と、コーディングエージェント用サンドボックス「Strands Box」のCLI対応が、Strands公式ブログで発表されました。どちらもWhat's Newの投稿はなく、AWSのサービスとしてではなくオープンソースとして出ています。

Strands Decider v2：判断専用のオープンモデル

Deciderは「システム1」型のモデルで、テキストを生成するのではなく、与えた選択肢ごとに確率を1回の推論で返します。用途はモデルルーティング、ツール選択、ガードレール、分類のような、エージェントの細かい判断です。v2はGoogleのGemma 4をベースにした5サイズ（E2B、E4B、12B、26B-A4B、31B）で、ライセンスはApache-2.0、重みはHugging Face、コードはオープンソースのStrands Deciderリポジトリにあります。

変更点は、v1のポインタヘッドをやめて選択肢トークンを直接読み取る方式にしたこと、学習データを1,748万件に増やしたこと、エージェントのトレースのような長い入力に合わせた調整です。公開ベンチマーク6件の平均は31Bで82.1（v1の26B-A4Bは70.0）とAWSは報告しています。実例として、Amazon社内の大規模チケットシステムでラベル付けをClaude Sonnet 4.6からDeciderに置き換え、コスト98%減・応答78%高速化という数字も挙げられています（いずれもAWSの発表値）。

Strands Box：エージェントを箱の中で走らせる

Strands Boxは2026年10月に出たオープンソースのOSサンドボックスで、11月23日にBox CLIがClaude Code、Codex、Kiro CLIにネイティブ対応しました。box run claude のように、自分のマシンに入っているエージェントをそのまま箱の中で起動できます。狙いは、承認を毎回求めるか、権限を全部渡す（いわゆるYOLOモード）かの二択をやめ、「箱の中では自由に動けるが、届く範囲は先に決めた境界まで」にすることです。

仕組みは、エージェントをOSサンドボックス内で動かし、ファイルアクセス、シェルコマンド、ネットワークリクエスト、MCP呼び出しのすべてをBoxがポリシー（Dogwoodというポリシー言語で記述）と照合します。判定はモデルの外で行われるため、エージェントが読んだ内容で判定が変わることはありません。APIキーなどの認証情報は箱の外に置かれ、エージェントにはプレースホルダが見え、出口のゲートウェイが実キーに差し替えます。対応環境はAppleシリコンMac（macOS 15以降）とLinux（ARM64／x86-64）で、Box自体はプレビューです。

ハイパーバイザ層で分離するNitro Sandboxesとは層が異なり、Boxは自分のマシン上のエージェントにOSレベルの境界を付けるものです。
