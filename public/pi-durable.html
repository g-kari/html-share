Pi と Pi Durable

手元でコードを書かせるなら Pi。
再起動をまたぐエージェントアプリを作るなら Pi Durable。

同じモデルの大小版ではない。Piはコーディングエージェントの完成品と拡張基盤、Pi Durableは会話・タスク・状態の永続化を組み込むライブラリ。両者を置き換え関係として捉えないのが出発点。

根拠：Pi 1.0公式発表

永続化は「副作用が必ず一度だけ」の保証ではない

会話、モデル呼び出し、ツール呼び出しをチェックポイント付きのタスクとして扱う。プロセスが落ちても、同じ永続ストアを開き直すことで未完了の処理を再開する。MemoryStorageだけでは、プロセス終了後にデータは残らない。

入力を受理 → 会話とタスクを保存 → モデル／ツール実行 → 結果を保存
中断 → 同じストアを再オープン → 保存済み状態から再開

同じrequestIdによる入力重複の排除と、外部サービスへの送信重複の排除は別問題。安全に再実行できるツールかを宣言し、Issue作成・課金・公開などは送信先側の冪等キーや結果照合まで設計する必要がある。

根拠：公式のクラッシュ回復・ツール再実行の説明、保存と再開

例えば「Issueは作成されたが、応答を受け取る前に落ちた」場合。無条件でPOSTを繰り返す実装は避け、永続化した識別子で既存Issueを確認する。これは本ページの設計上の提案であり、ライブラリが任意のAPIに自動適用する機能ではない。

Cloudflareで動かす構成

Cloudflare公式にはAgents SDKのPiHarness統合がある。Piが会話と実行を担当し、Durable ObjectのSQLiteに記録を保存。Lifecycleのジョブとalarmが、退避・再起動後の処理再開を支える。PiHarness自体もBeta。

Web／チャット画面
↓ HTTP・WebSocket・RPC（アプリ側で設計）
Agents SDK + PiHarness + Pi Durable
↓ Durable ObjectのSQLite／Lifecycle
モデル接続・用途別ツール・必要なら別の実行環境

Workers AIやAI Gatewayへの接続例も用意されている。ただし、この構成だけで一般的なNodeのシェルや任意バイナリがDO内で実行できる、という意味ではない。コード実行環境は別途選び、権限を限定する。

根拠：Cloudflare Pi統合（2026-10-05更新）。最後の実行環境の区別は、公式の保存層と実行環境の分離を踏まえた設計上の注意。

小さく試す順番

Pi：まずは隔離した開発用ディレクトリ

npm install -g --ignore-scripts @earendil-works/pi-coding-agent
cd /path/to/disposable-project
pi

公式READMEの必要条件はNode.js 22.19以上。Pi内のログイン操作で利用するプロバイダーを設定する。公式インストーラーは依存関係を固定する一方、npm経由は推移依存まで固定しないと説明されている。上記は手順紹介で、本ページ作成時にインストールや有料API実行はしていない。

根拠：公式導入手順

Durable：外部書込みなしの回復試験から

  1. 対象バージョンとlockfileを固定する。確認時のmain上のdurable package.jsonは1.0.4。npmの最新配布版と同一とは断定しない。
  2. 公式Quick Startで構造を理解し、永続化試験はMemoryStorageからSQLiteへ切り替える。
  3. モデルとツールをモック化し、同じrequestIdの入力を二度送る。
  4. 処理途中でプロセスを停止・再起動し、タスク・会話・結果が復元されるか確認する。
  5. 読み取り専用ツールから接続し、外部書込みは結果不明・権限失効・再試行の試験を加えてから有効にする。

仕様根拠：Durable README、package.json。試験順序は本ページの提案。

費用は三つに分けて見る

  • ソフトウェア：PiとPi DurableはMIT。導入先や第三者サービスの費用は別。
  • モデル：利用するAPI／契約に依存。長い会話、再試行、要約にも推論コストが発生し得る。固定の「Pi月額」だけでは見積もれない。
  • 実行・保存：ローカルなら端末やVM、CloudflareならWorkers/DO・SQLite・別途モデル等を合算する。

Workers Paidの最低料金は月額$5。DOのPaid枠を超えた単価は、リクエスト100万件あたり$0.15、duration 100万GB-sあたり$12.50。SQLiteは保存5GB-monthを含み超過$0.20/GB-month。無料枠・読書き行数・Workers本体・モデル料金は別に確認する。待機中でも休止できないDOはduration課金対象となる。

料金根拠：Cloudflare DO料金表（2026-10-06確認、USD）。これは構成全体の見積額ではない。

採用前に押さえる境界

Piは起動したOSユーザーの権限でファイルを読み書きし、実行できる。作業フォルダやプロジェクトの信頼設定は、OSサンドボックスの代わりにならない。Extensionsや外部プロセスも含め、コンテナ・VM、限定された資格情報、ネットワーク制限を別に考える。会話の保存・共有にはファイル内容やコマンド出力が混ざり得る。

根拠：Run Pi safely

「長く動く」と「放置して安全」は違う

本ページの推奨設計：書込み先を許可リスト化し、送信と承認の記録を残す。承認は対象・内容・期限に結びつけ、再起動だけで別操作へ流用しない。権限失効時は安全側で停止する。ログ保存期限とバックアップ復元試験も決める。

個人開発での使い分け案

日々の修正：Piで差分作成とローカルテスト。継続運用：Pi Durableで、エラー受付→重複判定→修正候補→レビュー待ち、という状態を保持する。単純なRSSの定期取得は通常のcron/キューで十分な場合もある。会話からの追加指示、長い承認待ち、再起動後の継続が必要になった地点でDurableの価値が大きくなる。

ただしDurableを入れるだけでCI、購読追加API、GitHubへの権限管理が完成するわけではない。既存の安定した処理を丸ごと置き換えるより、読み取り専用の小さなPoCで中断・復旧・費用を測るところから始めたい。
