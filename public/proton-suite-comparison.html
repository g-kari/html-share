まず、Proton は５つの主な道具

同じ会社・同じアカウントで使えても、役割は別です。VPN を入れても、メール本文やパスワードの保管方法までは変わりません。

「無料」と「まとめ契約」を混同しない

無料でも、Mail は１アドレス、Calendar は３カレンダー、Pass はログイン保存数・端末数が無制限。VPN は１接続・自動選択の10か国です。Mail の初期500 MBを最大1 GB、Drive の初期2 GBを最大5 GBに増やすには、各サービスの開始タスクを完了する条件があります。

ほかにもある Proton のサービスと、追加料金の注意

Docs / Sheets

Drive 内の文書・表計算。無料版から利用可能。Docs は DOCX 等、Sheets は XLSX・CSV・TSV の入出力に対応。形式対応だけで、Word / Excel の全機能や見た目の互換性が保証されるわけではありません。

根拠：Proton Drive 料金 / Proton Docs の取り込み・書き出し / Proton Sheets の取り込み・書き出し

Authenticator

無料の２段階認証アプリ。アカウントなしでも使え、任意で暗号化同期。Windows・Mac・Linux・iOS・Android に対応し、コードの取り込み・書き出しができます。Pass 内蔵の認証コード機能とは別製品です。

根拠：Proton Authenticator の仕様

Meet

暗号化ビデオ会議。Unlimited / Duo / Family でも基本は Free の50人・60分、１日５つの新規会議リンク。Professional は100人・24時間、$95.88/年（$7.99/月相当）。有料 Meet が含まれるのは Workspace / Visionary 等です。

根拠：Proton Meet の料金と制限 / Proton プランの公式説明

Lumo

AI アシスタント。Unlimited / Duo / Family は制限付きの無料枠。Plus は $119.88/年（$9.99/月相当）。履歴の保管時暗号化と、入力を AI が処理することは別です。Web検索では簡略化した要求を提携APIに送る場合があり、任意のフィードバック送信にも別のデータ共有があります。

根拠：Lumo 料金 / Lumo 入力処理・履歴・外部検索 / Proton プランの公式説明

SimpleLogin / Standard Notes

SimpleLogin はメールの別名を転送する道具。Premium は $36/年または $4/月で Pass の有料機能を含み、逆に Pass Plus にも高度な別名機能が統合されています。二重契約の前に付属範囲を確認してください。

Standard Notes は暗号化メモ。無料版のほか $90/年・$120/年の別料金を掲載。Unlimited の特典一覧で有料版の付属を確認できなかったため、ここでは別契約扱いです。

根拠：SimpleLogin の料金・Pass との関係 / Pass Plus と SimpleLogin の統合 / Standard Notes の別料金 / Proton プランの公式説明

Wallet / Scribe

Wallet は自分で鍵を管理する Bitcoin ウォレット。メールやファイルの保護に必要な道具ではありません。確定した送金は原則取り消せず、資産の復旧手段は別途必要です。

Scribe はメール文章作成支援。個人の Unlimited / Mail Plus では追加オプション、Duo / Family の料金ページでは付属と説明されています。

「暗号化される」は、３段階に分けて読む

通り道の暗号化

TLS / HTTPS

運んでいる途中の盗み見を防ぐ方法。受け取るサーバーは中身を処理できます。多くの一般的なサービスも採用しています。

保管時の暗号化

鍵は誰が持つ？

倉庫のデータを暗号化する方法。会社が鍵を持つ場合と、会社が開けられない「ゼロアクセス」方式は違います。

両端だけで開く

E2EE

送り手・受け手の端末だけで読める形にする方法。提供会社も本文の鍵を持ちません。ただし端末、相手、付帯情報のリスクは残ります。

根拠：Proton Mail 暗号化の範囲 / Proton Mail プライバシーポリシー

自動更新・解約・返金で見落としやすいこと
  • Proton のWeb購入は自動更新。規約では更新時の価格変更があり得ます。
  • 30日返金は、最初の購入から30日以内に解約と返金申請の両方が必要。現金・銀行振込は返金対象外で、利用者あたり１回という条件があります。
  • Drive の旧バージョンは容量に数えられます。「最大10年」は保存設定・200個の上限・空き容量も含めて読む必要があります。
  • 無料版への変更前に、容量・アドレス・カレンダー等を無料枠に収める必要があります。使わないだけで請求が止まるとは限りません。
  • 容量満杯や料金未払いは、メール受信・ファイル追加等にも影響します。単に保管庫の問題だと思って放置しないでください。

VPN

Proton VPN / Mullvad / iCloud プライベートリレー

Proton VPN

無料はデータ量制限なし・１接続、10か国から自動選択。有料は同時10台、国選択、P2Pやストリーミング向け機能。Mail / Pass / Drive とまとめる用途にも向きます。

OS別に機能差があります。拡張機能の保護範囲と、端末用VPNアプリの範囲も同じではありません。速度・動画視聴の成功をこの資料では実測していません。

根拠：Proton VPN 料金と更新額 / Proton 個人向け料金

Mullvad

€5/月（税込）、長期にしても月単価は同じ。５台、ポート転送は非対応。初回大幅値引きより、単純な料金やアカウント番号方式を好む人の比較候補です。

14日返金の説明がありますが現金は対象外。残高を追加して使う方式なので、Proton の自動更新契約とは読み方が違います。

根拠：Mullvad 料金・台数・返金

予定

Proton Calendar / Tuta / Google / Apple

予定の中身を守りたい

Tuta も暗号化カレンダーを提供。無料１個、有料は個数無制限と記載。独自アプリ中心の運用を受け入れられるかが判断点です。

選ぶ前の質問：自分だけの予定か、家族・仕事で共同利用する予定か。外部アプリでの編集が必要か。プライバシーと連携のどちらがその予定に重要か。

根拠：Google Calendar と Apple Calendar の連携 / iCloud の暗号化対象と例外

安全に使えるかは「なくしたとき」で決まる

根拠：Proton の復旧フレーズ

アカウント復旧 ≠ データ復旧

メールやSMSでパスワードをリセットして入れても、古い暗号化データが開かない場合があります。事前に有効化した復旧フレーズは、アカウントとデータの両方を回復する手段です。復旧設定をしてから、重要データを集める順番が安全です。

復旧フレーズ、２段階認証の予備、保管庫のバックアップは目的が違います。一つ用意しただけで全部を代替したつもりにならないでください。

根拠：Proton の復旧フレーズ

ほかの候補でも、復旧準備は必要

Bitwarden は会社によるマスターパスワード再設定ができず、事前の緊急アクセス等が助けになります。1Password Families は家族管理者がメンバーの復旧を支援する仕組み。Tuta はパスワード・第二要素・復旧コードの組み合わせが必要で、パスワードと第二要素の両方を失うと復旧コードだけでは戻せません。

根拠：Bitwarden 復旧の限界 / 1Password 家族メンバーの復旧 / Tuta クライアント・復旧・書き出し

自分に合う選び方

メール・VPN・パスワードをよく使う

Proton Unlimited を比較の起点に。500 GBで足り、専用アプリや Calendar の連携制約を受け入れられるなら、契約をまとめる価値があります。復旧を一か所に頼らない準備もセットです。

使い回しパスワードをなくしたい

Pass Free / Bitwarden Free で十分な場合が多い。メール移転や有料VPNを同時に始める必要はありません。別名メール重視なら Pass、独立保管庫と低費用重視なら Bitwarden が候補。

家族の写真とバックアップが中心

Apple中心なら iCloud+、端末混在なら Proton / Google / OneDrive の使い勝手を比較。2 TB / 3 TB は共有総量なのか個人別なのか、暗号化の設定と共有時の例外も確認。

仕事相手と Word / Excel / 予定を共有

既存の Microsoft / Google を主力に残す選び方。Protonは個人の保管やメールに使い分けられます。会社の運用・情報管理ルールに反して仕事データを移さないでください。

VPNだけ欲しい、長期契約は避けたい

Mullvad の固定 €5/月と、Proton の無料 / 有料を比較。端末数、国選択、使うアプリの保護範囲を先に決め、初回値引きだけで選ばない。

暗号化ファイルだけ大容量で保管

Drive Plus / Duo、Tresorit、Sync が候補。容量だけでなくLinux、同期、ファイル上限、復旧、出口を比較。価格が取得できない候補を、最安とは断定しません。

用語を、ふつうの言葉にすると

E2EE（エンドツーエンド暗号化）
送り手と受け手だけが開ける箱。提供会社にも中身を開ける鍵を渡さない方式。
ゼロアクセス暗号化
保管会社が中身を開けられない形で保存すること。外部との通信全体まで同じ方式とは限らない。
メタデータ
中身以外の情報。「誰から誰へ」「いつ」「どれくらい」など。本文が隠れても残ることがある。
VPN
端末から別のサーバーまで作る暗号化された通り道。アカウント名やCookieまで消すものではない。
IPアドレス
ネット上の接続元・接続先を区別する住所のような番号。個人名そのものではない。
別名メール（alias）
本当の受信箱に転送する別の宛先。サイトごとに作れば、漏れた先の切り分けや迷惑メール停止に役立つ。
パスキー
長いパスワードをサイトへ入力する代わりに、鍵の仕組みと端末の承認でログインする方法。引っ越し対応は別問題。
２段階認証 / TOTP
パスワード以外にも本人確認を求めること。TOTPは短時間で変わる認証コード。予備コードも用意する。
IMAP / SMTP・Bridge
メールを読む・送るための標準的な接続方法。Proton の Bridge はPC内で暗号化を解き、対応メールアプリにつなぐ仲介役。
ICS / CalDAV
ICSは予定を持ち出すファイル。CalDAVは予定を継続して読み書きする接続方法。ファイルの引っ越しと同期は別。
独自ドメイン
自分で契約した名前のメールアドレス。メール会社を変えても宛先を保ちやすいが、維持費と設定管理が必要。
監査・オープンソース
監査は特定範囲を調べる検査。オープンソースはコードを読めること。どちらも「不具合も事故も絶対ない」という保証ではない。
