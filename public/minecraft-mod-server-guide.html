01 / DECISION

まずは、この3通りから。

8人・大型パックなら、16GBで費用を抑えて検証するか、24GBでメモリの余白を取る。海外の安さは設置地域まで見て判断する。以下の選定は実測順位ではなく、今回の条件に対する提案。

16共有vCPU・SSD 320GB。価格は有力だが、日本の参加者に対する通信遅延は未測定。安さだけで欧州に決めない。[7][8]

3か月以上の前払いを許容するなら、シンVPSも比較対象。 大容量メモリ16GBは3か月契約で月額換算4,800円、初回3か月分は14,400円。1か月更新の掲載料金は4,900円だが、新規契約の最低利用期間は3か月。[2]

公開価格の確認と性能の実測は別。このページでは同一MOD・同一ワールドでのベンチマーク、申込画面の最終見積、空き在庫を確認していない。

02 / JAPAN VPS

国内の普通のVPSを比較

公式の円建て掲載料金を使用。月払い、月額上限、更新料金を区別し、年間契約の割引換算は主表に混ぜていない。OS・Java・MODパックの構築と運用は自分で行う前提。

為替は実勢レートではなく、編集可能な試算用の仮定。 人数の変更は費用の分担計算だけに適用し、対応人数や推奨スペックを変更しない。海外の円換算には税・IPv4追加料金・決済手数料を含めない。

8人割りは四捨五入。前払い総額は月額換算と別。バックアップ用の別ストレージや追加オプションは含めていない。各行の出典から契約時の税区分・総額を確認する。

シンVPSの料金は前回答から訂正。 「16GB 6,760円／32GB 16,560円」は今回確認した公式表と一致しないため不採用。更新時の1か月料金は4,900円／12,001円。値下げと断定せず、前回答の誤記として扱う。[2]

03 / GLOBAL OPTIONS

海外事業者も、設置場所で分ける

「海外の会社」と「海外のデータセンター」は別。AWSやAkamaiは日本リージョンも選べる。海外拠点を使う場合は、8人の実際の回線から接続感を確認する。[11][28]

表示の円換算は参考値であり支払総額ではない。契約通貨を優先。Hetznerは税・IPv4別、その他も税・追加オプション・転送超過等を契約画面で確認する。地域ごとの当該プランの作成可否は未確認。

月払い表と分けて見る広告価格

OVHcloud VPS-4 / 24GB：US$23.37〜 / 月

8 vCore・NVMe 200GB。 アジア向け公式ページの税別「From」価格。設定画面へのリンクに pricing=upfront12 が含まれるため、単月の継続料金とは扱わない。シンガポール選択後の契約総額・前払額は未検証。[14][15]

シンガポールなどAPACのVPS-4は転送量3TB/月、上限後は10Mbpsに制限される案内。「転送無制限」という別地域の説明をそのまま当てはめない。最終見積と接続試験が取れれば、国内VPSとの比較を続ける価値がある候補。[14]

欧州の価格差は大きいが、遠い

HetznerのCX43/CX53は欧州の低価格候補。一方、シンガポールのCPX42は16GBで€93.49/月と料金体系が異なる。同じ会社だからアジアも欧州と同じ安さ、ではない。 2026年6月15日の改定後料金を使用した。[7]

安い大容量RAMにも落とし穴

Akamai High Memory 24GBはUS$60だが、CPUは2、ディスクは20GB。追加ストレージやCPU負荷を考える必要があり、大型パック向けの即決候補とはしない。LightsailはCPUバースト残量も監視する。[13][12]

04 / GAME SERVICES

ゲーム向けサービスも比較に残す

構築できる人でも、管理の手間や価格によっては候補になる。ただし、管理型サービスとroot管理できるVPSを同じ自由度とは見なさない。任意のServer Files、MODローダー、Java、起動引数、追加UDPポートへの対応を確認する。

ConoHa for GAMEの初回割引を、ずっと続く月額として扱わない。 主表は通常時間課金の月額であり、長期割引パスの更新料金ではない。パスは契約期間分の前払い、キャンペーンは原則初回のみ。[17]

参考として、8GBはXServer GAMEsが2,500円/30日、ConoHa for GAMEの通常時間課金が月額7,348円。ただし今回の「8人・大型パック」では主候補を16GB以上に置く。これは運用上の提案で、パックの公式要件を置き換えるものではない。[16][17]

05 / SIZING & PERFORMANCE

人数だけでは、必要スペックは決まらない

下表は契約候補を絞るための目安。各社の「推奨人数」や接続スロット数を、大型MODパックの性能保証として転用しない。

8人 / 16GB

費用優先で、まず検証

パックの推奨要件を満たすなら試す起点。OS・Javaのヒープ外・バックアップ処理の分も確保する。RAM全部をJVMに割り当てない。

8人 / 24GB

メモリの余白を取りやすい

今回の比較の基準にしやすい容量帯。パック固有の上限設定や推奨値を優先し、使用量を見て調整。16GBより必ず速いわけではない。

8人 / 32GB

メモリ不足への備え

高い実使用量が見込まれる場合や複数処理の同居に余裕。ただし工業設備やチャンク処理のCPUボトルネックはRAM増量だけでは解決しない。

20 TPSと50msを確認する

Minecraftは通常20 tick/秒で進むため、1 tickの処理時間は50msが境目。sparkなどでTPS・MSPT・GCを確認し、メモリ不足とCPU処理の遅れを分ける。[18]

推奨する試験：8人が探索する場面と、工業設備が稼働する場面を別々に計測。平均だけでなく継続的な遅延や高パーセンタイルを見る。各社の同条件実測は本調査では未実施。

最低要件と8人快適動作は別

All The Modsのサーバーガイドには、多くのパックで6GB以上の割り当てという目安がある。ただし、これは8人で発展したワールドを遊ぶ保証でも、VPS全体6GBで十分という意味でもない。[19]

一般的な選定目安として、2〜4人・軽めなら4〜8GB、4〜8人・中規模なら8〜12GBも検討できる。実際はパックの指定要件と実測を優先する。

ラグの切り分け： TPSが維持されているのに操作応答が遅いなら回線・通信経路も疑う。MSPTが増え続けるならサーバー処理を調べる。vCPU数は物理コア専有の意味ではなく、共有状況・CPU世代・1スレッド性能の確認が必要。Hetznerも共有CPUでは負荷により性能が変動すると案内している。[18][9]

06 / HOME WITHOUT PORT FORWARDING

自宅でポート開放しない場合

レンタルに決める前の比較用として収録。Minecraftの計算処理は自宅PCが担当するので、どの方式でも自宅PCの常時稼働、回線、電気代は残る。

参加者に追加ソフト不要

playit.gg

無料 / Premium US$3/月
友達 → playit中継 → 自宅エージェント → Minecraft

ホスト側でエージェントを起動し、参加者には接続先を渡す。自宅ルーターでの転送設定を避けたい場合の試しやすい方法。[20]

中継を含む通信経路は実測。無料版・有料版とも低遅延を保証するものではなく、PCのスリープや再起動対策は別途必要。

参加者にもVPNアプリが必要

Tailscale

無料 / Personalの条件内
友達のTailscale → 直接接続または中継 → 自宅

同一Personalネットワークは最大6ユーザー。 今回の8人全員を同じ無料ネットワークへ招待する案には、そのまま使えない。端末共有を使う別構成などの条件を確認する。[21][22]

必ず直接接続できるわけではない。tailscale statusで接続方式を確認。共有はMinecraft用端末・必要ポートに絞る設計を推奨する。[23]

入口だけを小型VPSに置く

国内VPS + frp

550円〜 / 月額上限の例
友達 → 公開VPS → frpトンネル → 自宅

KAGOYAの1GBプランを使う例では月額上限550円。中継に必要な余力は別途検証。frpはTCP/UDPの転送に対応する。[4][24]

自宅のポート転送は不要でも、VPS側の受信用ポートは必要。OS更新、認証、暗号化、帯域管理などの運用が増える。

Cloudflare Tunnelは別の前提

TCPの公開ホスト名経由では、利用者側にもcloudflared access tcpなどが必要。通常のMinecraftクライアントに接続先を入れるだけ、という用途では第一候補にしない。[25]

音声MODは別ポートにも注意

Simple Voice Chatには追加のトンネル・音声接続先の設定が必要になる。ゲーム本体に入れても音声が通るとは限らない。[26]

電気代まで入れると差が縮む

増える消費電力を100W、単価を31円/kWh、24時間×30日と仮定すると、月2,232円。

0.1kW × 24時間 × 30日 × 31円。これは説明用の仮定で、現在の電力単価や実測消費電力ではない。普段からPCを稼働している場合は増分で比較する。

今回のように「8人で長く遊ぶ・自分でVPSを構築できる」なら、最初からレンタルへ切り離す選択は合理的。トンネル設定や自宅の停止リスクを減らせる。

07 / BEFORE COMMITTING

長期契約する前に、ここを確認

料金表を見ただけで決めず、実パックを使った検証から本運用へ進める。

Server FilesとJavaの組み合わせを固定

パック配布元のサーバー用ファイルを使い、Minecraft・Forge/NeoForge/Fabric等・Javaの指定バージョンを合わせる。任意の最新版へ一括更新しない。[19]

8人の実プレイで、メモリ・tick・通信を分けて測る

探索、拠点稼働、バックアップ時を確認。RAMが余っているのにMSPTが悪い場合は、CPUや重い処理を調べる。Lightsailではバースト残量も見る。[18][12]

復旧できるバックアップを用意

ワールドだけでなくMOD・設定・バージョン情報も保存。別保存先を設け、復元を試す。バックアップの取得方法はパックに合わせ、無整合な稼働中コピーを避ける。これは本ページの運用提案。

入口を絞り、管理ポートを公開しない

身内サーバーはonline-mode=trueとwhite-list=trueを基本にする。SSHは鍵認証と接続元制限を検討し、RCONは外部公開しない。ポート転送が不要でも、トンネルの公開先には外部から接続できる。[27][24]

更新費・増強・撤退条件まで確認

初回割引終了後、最低利用期間、容量変更時の停止、転送超過、IPv4、追加ディスク、バックアップ料金を確認。例としてIndigoは停止しても削除までは時間課金が続く。[3]

XServer VPS クラウド：前回答の16GB 9,801円〜・32GB 24,570円〜は、今回公式ページで再検証できなかった。現行価格の比較表から除外し、未確認の過去参考値としてのみここに残す。従来XServer VPSの新規受付状況も、このページでは現在の状態を断定しない。
