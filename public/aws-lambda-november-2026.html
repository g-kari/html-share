AWS Lambda 2026年11月の変更：GPU対応とdurable functions、MicroVMsの拡張

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. Managed InstancesでGPU推論に対応（11月18日）。ドライバーやスケーリングの管理なしに、vLLM等の事前構成イメージでGPUワークロードを動かせます。
  2. durable functionsは一時停止／削除、OpenTelemetry、Rust SDKのGA、既定クォータの大幅引き上げ（実行中500万件など）が入りました。
  3. MicroVMsはx86対応と7リージョン追加。カスタマーマネージドランタイムで、ランタイムの中身を一元管理して再デプロイなしに配れるようになりました。
  4. 細部では30分タイムアウト、SQS FIFOバッチ1万件、Node.js 26／Python 3.15ランタイム追加などがあります。

概要

AWS Lambdaの2026年11月は18件と、単独サービスでは多めの月でした。目玉は実行形態の拡張で、Managed InstancesでのGPU対応、durable functionsの機能追加、MicroVMsの対応拡大が並びます。あわせて、カスタマーマネージドランタイムという運用の仕組みも入りました。

Managed InstancesでGPU推論（11月18日）

Lambda Managed Instancesで、EC2 GシリーズのGPUインスタンスを使ったGPU加速Event Functionsが動くようになりました。AI推論、メディア処理、3Dレンダリング、科学計算、金融シミュレーションが対象で、GPUドライバーやフレームワーク、スケーリングの管理は不要です。vLLM、SGLang、PyTorchを事前構成したGPUベースイメージが用意され、GPU利用率や同時実行数に応じてスケールします。通常のEvent Functionsと同じ200以上のイベントソースと組み合わせられます。

Managed Instances自体にも、ゼロへの／ゼロからのスケール（11月17日）と、Event Functions向けコスト最適化レコメンド（11月20日）が入りました。

durable functionsの拡充

チェックポイントと自動リトライを持ち、最長1年動く多段処理のためのdurable functionsは、11月に4件の更新がありました。実行の一時停止と削除、OpenTelemetryトレーシングへの対応、Durable Execution SDK for Rustの一般提供、そして既定クォータの引き上げです。クォータは実行中のdurable executionがアカウントあたり100万→500万、開始レートが300→3,000リクエスト/秒など、大幅に上がっています（一部リージョンではその2倍）。

MicroVMsとランタイム

VMレベルの分離と高速な起動・再開を持つLambda MicroVMsは、x86アーキテクチャに対応し（従来はGraviton）、7リージョン追加とKMSカスタマーマネージドキー対応が入りました。AIコーディングアシスタントやCIランナー、脆弱性スキャナのような、利用者やジョブごとに隔離したい用途が想定されています。

ランタイム面では、カスタマーマネージドランタイムが新設されました。プラットフォームチームがランタイムの中身（承認済みSDK、証明書、セキュリティ／監視ツールなど）をOCIイメージとして一元管理し、関数の再デプロイなしに更新を配れる仕組みです。このほか、オンデマンドEvent Functionsの30分タイムアウト、SQS FIFOのバッチ上限10,000件、Node.js 26とPython 3.15のランタイム追加、Kafkaイベントソースのキュー処理などがあります。
