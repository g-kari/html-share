AWS ネットワーク・CDN 2026年11月の変更まとめ：CloudFront、Route 53、Interconnect

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. AWS Interconnectが一般提供になりました。Equinix経由のラストマイルと、Microsoft Azureとのマルチクラウド接続です。
  2. CloudFrontはオリジン相互TLSでのWebSocket／gRPC、Functionsからのネットワーク呼び出し、SaaS Managerの強化が入りました。
  3. VPC、Transit Gateway、Cloud WANはクロスリージョントラフィックで99.999%の可用性SLAを打ち出しました。

概要

ネットワーク・CDN分野の発表は37件です。CloudFront、Route 53、VPC、Direct Connect／Interconnect、Transit Gateway、API Gatewayなどを扱います。WAFは単独記事に分けています。

目立つ変更

  • AWS Interconnect：EquinixのデータセンターからAWSへのマネージド接続（ラストマイル）のプレビューに続き、Microsoft Azureとのマルチクラウド接続が一般提供になりました。
  • CloudFront：オリジン相互TLSでWebSocketとgRPCに対応し、CloudFront Functionsからネットワーク呼び出しができるように。欧州ソブリンクラウドでも提供開始しました。
  • Route 53：レコードセット保護、期限切れドメインのセルフサービス復旧、プライベートエンドポイントのヘルスチェック、Advanced Hosted Zones、Resolver DNS Firewallの許可リスト自動生成など、件数が多い月です。
  • Transit Gateway／ファイアウォール：ファイアウォールへリソースコンテキストを共有するセグメンテーションポリシー、Gateway Load Balancerとのネイティブ統合が入りました。
