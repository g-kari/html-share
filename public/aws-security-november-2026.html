AWS セキュリティ 2026年11月の変更まとめ：Cognito、IAM、STS、Security Hub、Network Firewall

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. STSが「GetScopedCredentials」を発表。既存の一時認証情報を持つエージェントやワークロードが、実行時に権限を絞った認証情報を取れる仕組みです。
  2. Cognitoは9件と多く、OAuth 2.0トークン交換、セッション管理、ポイントインタイムリカバリ、動的クライアント登録などが入りました。
  3. Security HubはコンピュートリソースのSBOMインベントリを提供開始。Network Firewallは次世代ポリシーと明示的プロキシ、自動インターネットファイアウォールを打ち出しました。

概要

セキュリティ・アイデンティティ分野の発表は38件です。WAF（単独記事）を除く、IAM／STS／Cognito、Security Hub、Inspector、Network Firewall、Secrets Managerなどを扱います。エージェントのIDまわりはAgentCore Identity（単独記事）も関係します。

目立つ変更

  • STS GetScopedCredentials（11月19日）：一時認証情報をすでに持つ主体が、実行時に権限を絞り込んだ認証情報を取得するAPIです。エージェントに広い権限を渡しっぱなしにしないための部品として、AgentCoreまわりとあわせて注目されます。
  • サインインと認可：AWS Sign-InのOAuth 2.0トークン交換、AIエージェント向けエンタープライズ管理認可、最大90日のサインイン期間設定。IAMにはアクセス拒否を調べるAccess Troubleshooterが出ました。
  • Cognito：トークン交換、ユーザープールのセッション管理、ポイントインタイムリカバリ、動的クライアント登録、Secrets Managerでのクライアントシークレット保管など9件。
  • 検出と防御：Security HubのSBOMインベントリとリソース重要度の推定、Inspector Code SecurityのGitHub Enterprise Server対応、Network Firewallの次世代ポリシー／明示的プロキシ／自動インターネットファイアウォール（プレビュー）。
  • シークレットと証明書：Secrets Managerのクロスアカウント複製と外部シークレット（Auth0、Okta、Palo Alto Networks）対応、KMSのRAM経由キー共有、Private CAのX.509条件キー。
