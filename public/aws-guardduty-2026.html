03 / Release notes

アップデート別の詳細

2026-10-08RDS注目度：高

RDS Protection：PostgreSQLデータ操作リスク検出

従来の認証・ログイン異常監視に加え、PostgreSQLに対するデータ流出や破壊につながるデータ操作を監視する追加機能。

技術的な意味・確認手順・料金条件

実施・確認すること

RDS Protectionのデータアクティビティ保護を検討。適用DBエンジン・バージョン・リージョン・有効化方式をAWSコンソールの機能表示と最新ドキュメントで確認。

注意点

自動で既存の全RDSが保護されるとは限らない。RDS_LOGIN_EVENTSとRDS_DATA_RISKを同一視しない。

コスト観点

新しい監視ディメンションには追加費用が発生しうる。30日間無料トライアルの対象と終了後料金を公式料金表・コンソールで確認。

2026-09-04Detection Rules注目度：高

Custom Detection Rules：選択式の追加検出

35種類の事前定義されたオプショナルなルールを選択して有効化可能。環境固有のリスクに合わせ、検出対象を拡充。

技術的な意味・確認手順・料金条件

実施・確認すること

GuardDutyコンソールのCustom Detection Rulesからルール一覧を確認し、最初はDry runでメトリクス評価、その後必要なルールだけ有効化。

注意点

自由記述のSIEMクエリを任意実行する機能ではない。Dry runは14日後に自動終了。

コスト観点

監視データ量・有効化ルール等に応じた課金条件を公式料金で確認。

公式資料を確認 ↗

2026-09-28Lambda注目度：高

Lambda認証情報の不正利用検出強化

AWS Lambda実行環境の認証情報が意図しない場所や形で利用された場合の異常検知範囲の強化。

技術的な意味・確認手順・料金条件

実施・確認すること

LambdaのIAMロール権限・一時認証情報露出経路・検出時のログ保全と認証情報失効／権限見直しを運用手順に含める。

注意点

Lambdaのすべての情報漏洩や実行時侵害を直接検出するわけではない。適用条件は最新Finding一覧で確認。

コスト観点

既存GuardDutyと他保護機能の料金の区別が必要。

公式資料を確認 ↗

2026-07-14AI注目度：高

AI Protection：Bedrock / SageMakerを対象とする保護

生成AIサービスへの悪意ある操作や不正利用に関する可視化・検出の対象が拡大。

技術的な意味・確認手順・料金条件

実施・確認すること

BedrockやSageMakerを実際に利用している環境で、対象の保護プラン・利用可能なリージョン・検出対象を確認する。

注意点

アプリケーションの全プロンプトや全AI呼び出しをGuardDutyだけで保護する意味ではない。

コスト観点

サービス別の保護・データ分析量による課金対象を確認。

公式資料を確認 ↗

05 / Playbook

いま確認する順番

保護対象を棚卸し。 RDS（PostgreSQL含む）、Lambda、Bedrock、SageMakerがどのリージョンで稼働しているか確認する。
現在のGuardDuty保護プランを確認。 管理アカウント・委任管理者、組織への自動有効化ポリシー、メンバーアカウントの違いに注意。
追加ルールをDry runで評価。 14日で期限が来る前提で、検出の質と運用負荷を観察する。
RDS Data Activityの適合条件を照合。 エンジン・バージョン・地域・追加料金・トライアル終了日を確認してから有効化。
検出後の対応経路を確認。 EventBridgeやSecurity Hub等への流通、CloudTrail証拠保全、対応Runbook、誤検知の扱いを点検。
費用を計測して判断。 トライアルやDry runから本番監視へ切り替える前に、実際の利用量とAWS Pricingを照合する。

これは運用確認手順であり、特定のAWSアカウントで実施・有効化したという記録ではありません。
