llama.cpp：安定版と開発版の更新

v0.6.0 の改善と、後から master に入った複数 GPU の MoE cache を分けて確認。

  • 10月5日の正式 v0.6.0 は、Qwen4Exp / Gemma4 の PLE tensor を先読みする llama_prefetch_rows と、Metal の F16 KV flash attention kernel などを追加。

Claude Max / Team に月次 API クレジット

対象の契約者が、自作アプリや API エージェントに使えるクレジットを受け取れる。

  • Max 5x は月 $100、Max 20x は $200。Team は Standard席 $20 / Premium席 $100を合算し、全体で月 $500 が上限。
  • 対象プランで7日以上経過後、Console 組織を1つ連携。組織側の Owner / Admin / Billing 権限が必要。連携先の自己変更はできず、追加のクレジット規約を確認する。

  • 連携組織の API キーで自分で起動する claude -p / Agent SDK は対象。残高後は購入済み分・自動補充など既存の請求設定に従う。
