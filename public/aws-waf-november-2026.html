AWS WAF 2026年11月の変更：料金体系の簡素化とAI／APIの自動保護

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. 料金体系が組み替わりました（11月23日）。リソース料金＋基本リクエスト料金＋高度な保護だけのプレミアム料金の3軸で、ルールを足しても料金は変わりません。無料枠は2,500 WCUに拡大。
  2. LLM／MCP／A2AエンドポイントとAPIの自動発見・保護が一般提供に。新マネージドルール「AI Security」（Bedrock Guardrails連携）と「API Security」（BOLA等に対応）が出ました。
  3. Security Analytics Dashboardが始まり、全Web ACL横断の分析とコンソール内ログ検索、21日分の全件データが追加料金なしで使えます。
  4. Bot Control標的型保護の導入が一括設定になり、ボット信頼度レベルとLATEST自動追随が入りました。WebBotAuthの検証状態もルールに使えます。

概要

AWS WAFは2026年11月に9件の発表があり、うち11月23日に3件が集中しました。内容は料金体系の組み替え、AIエンドポイントとAPIの自動発見・保護、分析ダッシュボード、Bot Controlの導入簡素化と、基盤に手を入れる変更がそろっています。9〜10月のWAF関連発表は2件だけで、変更は11月に集中しました。

料金体系：ルールを足しても料金が変わらない設計に（11月23日）

新しい料金は「何を守るか」に従います。従来はWeb ACL、ルール、ルールグループのサブスクリプション、キャパシティ階層ごとに別料金で、セキュリティの判断がそのまま請求の計算になっていました。新体系は3つの軸です。保護するリソースへのリソース料金、WAFが検査する全リクエストへの基本リクエスト料金、Bot Control標的型保護・Fraud Control・API Security・AI Securityといった高度な保護が評価したトラフィックだけへのプレミアムリクエスト料金です。

各Web ACLに含まれる無料枠は2,500 WCU（従来1,500）に増え、Bot Control共通保護やAnti-DDoSルールグループは追加料金なしで足せます。導入前にコストを見積もりやすくなった、というのが公式の打ち出しです。

AIエンドポイントとAPIの自動発見・保護（11月23日）

API Gateway、Application Load Balancer、CloudFrontの背後にあるAPIとAIエンドポイントを、AWS Organization全体で自動発見する仕組みが一般提供になりました。発見は新しいAPI Gateway API Portalが担い、トラフィックログとサービス設定から自動で識別するため、エージェントの導入やログ転送は不要です。文書化されていない公開MCPサーバーは「シャドウAPI」として現れます。

保護側は2つの新しいマネージドルールグループです。AI SecurityはLLM／MCP／A2Aエンドポイント向けで、プロトコル認識と準拠チェックで不正なMCP・A2Aメッセージを止め、コンテンツ検査を有効にするとAmazon Bedrock Guardrailsを呼んで、プロンプトインジェクション、ジェイルブレイク試行、有害コンテンツ、応答内の機微情報を検出します。API Securityは、BOLA（オブジェクトレベルの認可不備）、認証破りとクレデンシャルスタッフィング、APIの偵察と列挙という、悪用されやすいAPI攻撃カテゴリに対応します。どちらも追加料金の対象で、Guardrailsの呼び出しは別途Bedrock側の課金です。

Security Analytics Dashboard（11月19日）

アカウント内の全アプリケーションを横断して不要なトラフィックを見つけて止めるための、新しい分析ダッシュボードが始まりました。全プロテクションパック（Web ACL）のトラフィックを1つの画面に集約し、IPアドレス、国、ASN、ユーザーエージェント、JA4フィンガープリント、ホスト、パス、発火したルール、ラベルで絞り込みと集計ができます。データはサンプリングではなく全件で、コンソール内でリクエストログを直接検索でき、21日分の全件データが追加料金なしで含まれます。従来はWeb ACLごとに画面を開くか、ログをCloudWatch LogsやS3へ出してクエリする必要がありました。

Bot Controlまわり（11月17日・20日）

標的型保護の導入が簡素化されました。コンソールの「Targeted bot control」設定を入れると、推奨構成でルールグループの追加、各信頼度レベルの推奨アクション、LATEST版への自動追随、JavaScript SDKの自動統合までが一括で入ります。検出結果はリクエストごとにHigh／Medium／Lowの「ボット信頼度レベル」に集約され、ラベルマッチルールを書かずに扱えます。

また、AWS Agent RegistryがWebBotAuth（WBA）ボットの登録に対応し、検証済みボットかどうかとボットのIDを組み合わせたBot Controlのルールが書けるようになりました。正規のクローラーを通し、未検証のトラフィックを止める、といった出し分けができます。

その他の変更

  • 高度なレートベースルールの提供拡大（11月16日）：GovCloud（US）、タイ、メキシコで提供。カスタムキー（ヘッダー、Cookie、クエリ文字列、URIパス、メソッド、ラベル名前空間を最大5つまで複合）で集計でき、評価ウィンドウは従来の5分・10分に加えて1分・2分が選べます。追加料金はありません。
  • AIトラフィック収益化のStripe対応（11月5日）：AIボットやエージェントからの支払いを、ステーブルコインのままではなくStripe経由で現地通貨で受け取れるようになりました。WAFがHTTP 402を返し、有効な支払い資格情報で再リクエストされるとコンテンツを返す仕組みは従来どおりです。
  • Network Security Managerの拡大（11月11日）：WAFとShield Advancedのポリシーを自動適用するNetwork Security Managerが、欧州ソブリンクラウドと多数の商用リージョンで一般提供になりました。
