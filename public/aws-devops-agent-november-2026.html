AWS DevOps Agent 2026年11月の変更：サンドボックスとチャット連携

確認日：2026年11月24日
一次資料：AWS公式 What's New（2026年11月1日〜24日の投稿を全件取得）。各項目の見出しは公式発表へのリンクです。全体の索引はAWS 2026年11月の発表まとめ【索引】。

要点
  1. エージェントサンドボックス（11月20日）で、スキルに診断スクリプトを含めて実行させたり、エージェント自身にスクリプトを書かせて実行させたりできるようになりました。
  2. SlackのコードチャンネルとMicrosoft Teamsの双方向会話に対応。メモリ管理の高度化と調査レイテンシの短縮も入りました。
  3. GovCloud（US-West）で提供開始し、FedRAMP Class D認証を取得しました。

概要

AWS DevOps Agentは、運用調査を担うAWSのエージェントです。2026年11月は10件の発表があり、エージェントにスクリプトを実行させる「サンドボックス」、チャット連携、メモリ管理、GovCloudでの提供と認証が並びました。

見どころ

  • エージェントサンドボックス（11月20日）：スキルにチームの診断スクリプト自体を含められるようになり、エージェントがサンドボックス内でそのスクリプトを実行します。エージェント自身がスクリプトを書いて実行することもでき、たとえば複数のログクエリを並行して流して結果をつなぐ、といった分析がAPIのツール呼び出しよりも速く進みます。
  • チャット連携（11月19日・20日）：SlackのコードチャンネルとMicrosoft Teamsの双方向会話に対応し、新しいチャット機能も追加されました。
  • メモリと速度（11月16日・20日）：高度なメモリ管理機能が入り、調査レイテンシの短縮も発表されています。
  • 提供範囲（11月16日・20日）：GovCloud（US-West）で提供開始し、同リージョンでFedRAMP Class D認証を取得しました。EC2 Image Builderコンソールとの連携（11月12日）もあります。
