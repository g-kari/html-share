動画フレームワーク ＋ 公式スキル／プラグイン

Remotion

編集可能なコードから、尺の決まった動画へ。

React で画面と演出を組み、Studio で確認して動画にする。端末 UI、文字の出入り、パン／ズーム、カーソルを同じタイムラインに置く用途の第一候補。

  • 公式 Agent Skills は Codex／Claude Code などに対応
  • 制作・マークアップ・プレビュー・レンダーの専用スキル
  • Claude Code 用と Codex 用の公式プラグインも存在

注意：スキルが入るだけで動画が完成するわけではない。React プロジェクトとレンダー環境が必要。

公式スキルClaude CodeCodex

HTML 動画フレームワーク ＋ 公式スキル／プラグイン

HyperFrames

HTML と GSAP で組み、フレーム単位で動画化。

HeyGen が公開する HTML ベースの制作環境。専用の制作スキル、プレビュー、検査、レンダーが揃い、React を前提にしない。

  • Codex／Claude Code などのスキル対応エージェントで利用
  • motion-graphics、product-launch-video などの制作スキル
  • GSAP、CSS、Lottie、Three.js などのシーク可能な動きを扱う

注意：任意の HTML がそのまま正確な動画になるわけではない。時刻を指定して再現できるアニメーション設計が必要。

GSAP AI Skills

ズーム・強調・文字演出を細かく設計する。

公式の greensock/gsap-skills が存在する。タイムライン、SVG、文字、フレームワーク連携、性能の知識をエージェントへ追加できる。

  • Codex／Claude Code 対応を公式 README が明記
  • 端末 UI の複数要素を順序づける演出に向く
  • GSAP 単体は動画エンコーダーではない。MP4 化には別のレンダー工程

区別：GSAP の SplitText や MorphSVG は描画ライブラリの拡張。「AI エージェント用プラグイン」とは別物。

Web ライブラリ ＋ 公式スキル／MCP サービス

Motion AI Kit

React の UI 遷移や、ばね感のある動きに。

公式の /motion スキルとホスト型 MCP。最新ドキュメント検索とベストプラクティスは無料。有料の Motion+ で性能監査や高度な編集機能などが加わる。

  • Claude Code などは公式インストーラーの対象
  • Codex も案内対象だが、現行の導入ページの自動設定対象には明記なし。カスタム設定の確認が必要
  • 主用途はブラウザー内の UI。MP4 レンダーは別工程

注意：ローカルのスキルと外部 MCP 接続を分けて考える。既存の API キーを渡す旧手順は現行案内では廃止。

参考動画の雰囲気を作るなら

画面を分解

端末背景、等幅文字、選択行、カーソル、進捗、タイトルを別レイヤーにする。実画面キャプチャを使うなら秘密情報を除く。

見せる順番を決める

選択行へ視線誘導 → カーソル操作 → 進捗へ寄る → 短いタイトル。余白と読む時間を先に確保する。

短く試作する

10秒・1920×1080・30fps を仮仕様に、1シーンだけ作る。尺やフレームレートは参考動画の実測値ではない。

フレームで検査

開始・中間・切替前後・終了を静止画で確認。文字、ズームの端、カーソル、フォント読込、出力 MP4 の実再生をチェック。

そのまま試作依頼に使える要件案

10秒のソフトウェアデモを作る。黒い端末、白い等幅文字、薄紫の選択行、白い輪郭カーソルを使う。前半でモデル選択を示し、後半はダウンロード進捗へ滑らかにパン／ズームする。周辺文字を暗くして視線を誘導する。モデル名と数値は架空の例だと分かるものにする。

画面・文字・カーソルを個別に編集可能にし、任意の時刻へ移動しても同じ状態になるようにする。まず主要フレームで構図を確認し、その後 MP4 を書き出す。Web 版には一時停止・キーボード操作・動きを減らす設定への対応を入れる。

再現の難所は「どのツールか」より、文字の密度、動き始めと止まり際、ズームの焦点、読むための間。完成品質はスキル導入だけでは保証されない。

今回は主候補にしなかったもの

Manim：Python の数学・図解アニメーションライブラリ。数式や概念説明が主なら有力だが、今回の端末 UI デモには Web ベースの方が組み立てやすいという判断。公式の Agent Skill としては扱わない。公式資料

Motion Canvas：TypeScript で説明アニメーションを作る制作環境。ブラウザーの編集画面がある。これも通常のライブラリ／制作ツールとしての候補で、ここでは公式 AI プラグインの存在を確認していない。公式 Quickstart

生成動画サービス：背景や質感素材には使えても、正確な端末文字、数値、カーソル位置が必要なショットはコード再構築を優先する。特定サービスの契約や生成は行っていない。

導入前に確認すること

  • スキルは信頼境界の外：SKILL.md、同梱スクリプト、追加取得先を確認。ツールや秘密情報への権限は必要最小限にする。
  • レンダーはコード実行：npm 等のパッケージ実行、ブラウザー起動、FFmpeg、外部アセット取得が伴う。隔離した作業フォルダーで依存関係を固定する。
  • 素材と送信先：社内 UI、アカウント名、トークンを画像や外部 MCP に送らない。音楽・フォント・ロゴの権利も本体ライセンスとは別。
  • 再現性：乱数、実時計、ネットワーク待ちで変わる描画を避ける。フォントや素材を固定し、同じ時刻へ戻した結果を比較する。
