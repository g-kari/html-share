# AWS architecture icons used in the GuardDuty report

The 10 SVG files in `public/assets/aws-icons/` depict original AWS service icons, with no paths, colors, or proportions changed. The XML declaration was omitted to allow direct SVG delivery.

- Official AWS usage guidelines and downloads: https://aws.amazon.com/architecture/icons/
- Icon asset mirror: https://github.com/icacho-dev/aws-architecture-icons/tree/main/Architecture-Service-Icons_02072025
- Source package version: Architecture Service Icons 2025-02-07
- Icon names: Amazon GuardDuty, Amazon RDS, AWS Lambda, AWS CloudTrail, Amazon EventBridge, Amazon CloudWatch, AWS Security Hub, Amazon Bedrock, Amazon SageMaker AI, AWS Identity and Access Management.
- The icons only identify AWS services and do not imply that this is an AWS-authored page.
- Newer AWS icon versions may exist. Replace the files with updated official assets while preserving the link and license provenance.
- Do not apply image filters to the SVG itself. Glow effects are applied to surrounding containers instead.

For architecture diagrams, this report uses arrows to *illustrate concepts*, not to assert a particular integration is automatically enabled. GuardDuty findings can be routed through EventBridge; Security Hub integration is optional and not proof of the account's configuration.
